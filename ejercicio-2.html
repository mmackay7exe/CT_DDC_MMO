Sitio Web

BioBioChile

Tipo de layout: Corresponde a una Página Editorial / Multicolumna. Su objetivo central es ordenar una gran cantidad de noticias y notas secundarias en un espacio acotado.

Scroll y fijación: La mayor parte del sitio se mueve de forma continua, pero el menú superior usa position: sticky; al hacer scroll hacia abajo se compacta y queda anclado arriba para tener siempre a mano el logo, las secciones y la señal de radio.

Columnas y versión móvil: En pantalla completa organiza el contenido con CSS Grid y Flexbox en dos áreas claras: una columna principal ancha a la izquierda con las notas fuertes y un sidebar a la derecha para "lo más leído" y publicidad. Al achicar la ventana a tamaño celular, la grilla colapsa a una sola columna vertical y el menú se esconde dentro de un botón de hamburguesa.

Opinión y ajustes: La tipografía grande ayuda a leer rápido las noticias del día, pero el exceso de anuncios sin espacio reservado hace que el contenido salte bruscamente al cargar. Arreglaría esos contenedores de publicidad para que la lectura no se interrumpa.

Plataforma Web

Mercado Libre

Tipo de layout: Funciona como una Plataforma Web interactiva enfocada en transacciones, priorizando la búsqueda directa, carruseles de ofertas y catálogos dinámicos.

Scroll y fijación: El header amarillo principal se mantiene anclado arriba mediante position: sticky, asegurando que la barra de búsqueda y el carrito de compras nunca se pierdan de vista mientras recorres la lista de artículos.

Columnas y versión móvil: En el catálogo combina una barra lateral izquierda fija para los filtros (precio, marca, envíos) y una grilla modular flexible para las tarjetas de productos. En celular, la barra lateral desaparece para no apretar la pantalla y se resume en un botón flotante de "Filtrar", mientras que los productos permiten deslizarse horizontalmente con el dedo de forma natural.

Opinión y ajustes: Las tarjetas estandarizadas con el precio en verde y el sello "Full" funcionan excelente para comparar rápido sin marearse. Sin embargo, la portada repite demasiadas filas de carruseles casi idénticas; convendría agrupar mejor los bloques por categorías para no fatigar la navegación inicial.
